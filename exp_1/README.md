# Experiment 1 – Load and View the Dataset

## Aim

To implement a program to load and view the dataset.

## Algorithm

1. Load the dataset using Pandas.
2. Create a duplicate copy of the dataset.
3. Display the shape of the dataset.
4. Select the required columns.
5. Display the first 10 records.
6. Display dataset information.
7. Display summary statistics.
8. Check for null values.

## Dataset

**Music Library Songs Dataset**

The dataset contains **268 records and 21 columns**.

For this experiment, the following columns are selected:

- Song Title
- Album Title
- Artist Name 1
- Artist Name 2
- Artist Name 3

## Implementation

The dataset is loaded using Pandas and a duplicate copy is created. The selected attributes are then inspected using dataset shape, head, information, descriptive statistics and null-value analysis.

## Technologies Used

- Python
- Pandas

## Output

The program successfully displays:

- Dataset shape
- Selected columns
- First 10 records
- Dataset information
- Summary statistics
- Null values

## Result

Thus, the program to load and view the dataset was successfully executed.
