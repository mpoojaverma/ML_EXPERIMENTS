# Experiment 2 – Summary, Statistics and Visualization

## Aim

To display the summary and statistics of the dataset.

## Algorithm

1. Load the Music Library Songs dataset using Pandas.
2. Create a duplicate copy of the dataset.
3. Display the total number of songs and columns.
4. Display the dataset shape.
5. Display column data types.
6. Display the first three song titles.
7. Display the last three records.
8. Display the number of unique values in each column.
9. Display null values.
10. Display summary statistics.
11. Display the memory usage of the dataset.
12. Analyze the dataset using graphical visualizations.

## Dataset

**Music Library Songs Dataset**

The dataset contains 268 records and 21 columns.

## Analysis Performed

The following visualizations are generated:

### 1. Top 10 Artists – Horizontal Bar Chart

Shows the artists with the highest number of songs in the dataset.

### 2. Top 10 Artists – Vertical Bar Chart

Displays the same top artist counts using a vertical bar representation.

### 3. Album Distribution – Pie Chart

Shows the distribution of songs among the most frequently occurring albums.

### 4. Distribution of Songs per Artist – Histogram

Shows the frequency distribution of the number of songs associated with each artist.

### 5. Top Albums – Horizontal Bar Chart

Displays the ten most frequently occurring albums.

### 6. Artist Popularity Trend – Line Graph

Shows the song count of the top artists using a line representation.

### 7. Artist Song Count Spread – Boxplot

Displays the spread of the number of songs associated with artists.
